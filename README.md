# Prince Vyas — AI / Systems / FinTech Portfolio

A personalized, Persona-inspired technical portfolio for Prince Vyas.

## What this repository is

This repository is a customized derivative of the public
`Omicron69/persona5-style-portfolio` project. The original project supplied the
base interaction architecture, visual approach, and MVC structure. This version
replaces the original author's personal content and personal assets with Prince
Vyas's portfolio content and configuration.

The original project should be reviewed for its applicable copyright/licensing
terms before public redistribution. This repository does **not** claim the
original project's code or Persona/ATLUS intellectual property as original work.

## Structure

- `index.html` — portfolio screens and content surface
- `css/style.css` — visual system
- `js/model.js` — Prince Vyas data and GitHub configuration
- `js/view.js` — rendering and interaction presentation
- `js/controller.js` — navigation and event handling
- `assets/` — interface assets

## Run locally

```bash
python3 -m http.server
```

Then open `http://localhost:8000`.
