# Contributing

This is a personal portfolio rather than a general-purpose software project.
External contributions are not expected, but technical feedback and bug reports are
welcome.

## Before opening an issue

- Confirm the issue is reproducible.
- Include the browser and operating system when reporting a UI problem.
- Do not include credentials, private information, or sensitive data.

## Pull requests

If you propose a change, keep it focused and explain what the change improves.
Avoid introducing unnecessary dependencies or unrelated visual rewrites.
