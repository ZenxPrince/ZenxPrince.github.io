# Security Policy

## Scope

This repository is a static personal portfolio. It does not intentionally contain
credentials, API keys, private tokens, or server-side secrets.

## Reporting

If you discover a security issue in the site or repository, please avoid publishing
sensitive details in a public issue. Contact the repository owner through the public
contact channels listed on the portfolio and provide enough information to reproduce
the issue safely.

## Sensitive data

Do not submit passwords, API keys, access tokens, private documents, or other
sensitive personal information in issues or pull requests.
